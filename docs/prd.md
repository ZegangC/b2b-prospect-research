# 精简 PRD：标准调查与业务交付

状态：2026-10-07 回顾整理；既有规则与未来评估计划明确分开。

## 用户和目标

主要用户是需要扩充海外客户池的外贸业务人员。目标是从可追溯的企业资料得到可筛选的开发清单。执行人员维护调查过程，业务人员判断联系顺序和下一步行动。

## 既有范围

1. 候选发现：记录企业主体、国家、相关性证据、来源和初评。
2. 标准调查：整理产品、工艺、应用、公开规模线索、相关商务入口和缺失项。
3. 开发排序：五维评分及 A/B/C/D 等级，保留证据和理由。
4. 交付：在 Excel 中关联客户主档、联系人和来源。
5. 质量控制：检查唯一 ID、关联关系、分数、状态、来源、公式和可读性。
6. 定向补查：仅在业务人员指定企业和问题后执行。

## 范围外

未经授权的付费海关数据、无法证实的竞争报价、推测邮箱、自动承诺采购需求、无人审核发送开发信。邮件开发在另一工作流中，本公开仓库不包含发送功能。

## 核心验收标准

| 场景 | 预期行为 |
| --- | --- |
| 同企业重复发现 | 合并或标记复核，保留来源，不重复累计覆盖 |
| 已完成企业评级变化 | 更新开发优先级，不自动重新调查 |
| 未发现可靠商务入口 | 明确记录缺失，允许符合停止规则的终态 |
| 网页同时出现员工姓名和公司邮箱 | 不自动把邮箱归到该员工名下 |
| 高置信度公开邮箱但未联系 | 标记未实联，不推断可送达 |
| 未冻结候选池或仍有待研究企业 | 不宣布国家完成 |
| 结构化检查通过 | 仍需业务含义核验和国家级视觉验收 |

## 数据与评分

工艺匹配 35、潜在采购量 20、可触达性 15、外贸能力 15、开发难度 15（越容易得分越高）。总分 A ≥80，B ≥65，C ≥45，其余 D。

上述是当前业务优先级规则，不是经过统计校准的成交概率。潜在采购量只能按公开线索估计，不得冒充真实订单量；信息不足与已证实不匹配必须在理由中区分。

## 后续需测量的指标

固定样本的业务匹配一致率、错误联系人归属率、证据支持率、单家处理耗时、业务查看与采纳率。触达后的送达、有效回复和订单属于后续漏斗，不能与研究完成率混为一谈。
