# 案例：把企业调查整理成业务可用的工作流

这是 2026-10-07 对已有实践的回顾整理，非项目启动时形成的原始文档。

## 业务背景与角色

工业材料外贸团队原有获客方式主要是展会和转介绍。新的客户研究路径需要持续找到相关企业、判断其实际业务和应用匹配、整理公开商务联系入口，并帮助业务人员决定先联系谁。

项目发起人独立推进需求、流程、研究规则和交付迭代，借助 AI 工具开展研究及生成程序。这里的独立负责不等于全部代码手写，也不等于每条来源均经人工逐项核验。

## 使用反馈

根据项目负责人的业务沟通记录，研究表已交付四人外贸团队。资深业务员已有客户池，采用意愿较低；至少一名新业务员持续反馈。当前证据支持早期用户共创，不能支持全团队稳定采用。

业务反馈包括：字段较齐全，希望补充海关记录和竞争对手报价。这些资料的覆盖、授权、时效和成本尚需验证；没有把无法稳定获取的数据承诺为基础功能。

## 三项关键取舍

### 一次标准调查，按需补查

早期流程存在多次分级与复查。后来把“研究是否完成”与“A/B/C/D 开发优先级”分开：低等级可以完成研究，高等级也不自动进入第二轮。只有业务人员提出明确问题时才做定向补查。

收益是消除重复阶段和不清晰的停止条件；代价是少量复杂问题留待业务点名。没有同口径工时记录，因此不量化节省时间。

### 候选发现与标准调查分阶段

候选阶段收集主体、地区、相关性与来源，依据细分行业、地区、语言和来源覆盖判断是否冻结候选池。冻结后处理未终态企业，并保留既有成果。

收益是更容易管理覆盖和进度；代价是发现阶段不能把候选数量当作已完成研究数量。市场规模不同，不使用统一国家配额。

### 保留不确定性，交付业务能用的结果

生产环境用 Excel 交付，内部使用结构化记录、断点和验收脚本。公开联系人区分个人、公司入口和待核验线索。未找到资料也可以结束有边界的调查，明确记录缺失。

收益是业务人员可以筛选、追问并追溯来源；代价是仍需人工验证信息含义、现任关系及联系有效性。

## 结果与下一步

历史验收记录覆盖两个国家，详细口径见 [evaluation.md](evaluation.md)。研究覆盖已经形成，但采用率、联系人有效性、有效回复和订单归因仍需持续测量。

下一步最有价值的实验是：让早期用户对固定样本盲评，记录“值得开发”的原因，同时测量人工查找和辅助查找的时间、成本及错误率。没有这些数据前，不将技术产出直接写成商业增长。
