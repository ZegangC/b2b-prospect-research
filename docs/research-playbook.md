# 调查操作方法（公开整理版）

此文档从实际操作规则整理，不包含原始企业数据、公司专有产品指标或内部路径。它是一份人工与 Agent 协作的操作说明，不是可独立运行的搜索程序。

## 发现候选

- 每个市场先核实当地行业、工艺与企业角色的真实用语；使用英语和实际业务语言。
- 按“细分行业 × 产品/工艺 × 企业角色 × 地区/来源类型”组织搜索。
- 优先企业官网、行业协会、展会及政府/监管资料，交叉核对主体。
- 行业标签只能帮助发现，实际匹配需要产品、工艺或应用证据。
- 按细分行业、地区、语言和来源检查覆盖及新增有效主体情况，再判断是否冻结候选池。

## 标准调查

逐项分开记录事实、推断和未知。每条重要事实关联来源 URL、核验日期、可信度与具体支持内容。缺失公开信息写为未发现或待核验。

评分以证据为依据，但模型给出的数值仍是判断。校验总分与等级并不能证明判断正确。

## 联系人规则

查找公开用于商务的相关岗位入口，区分公司通用邮箱、明确归属于个人的工作邮箱、历史或归属不确定线索。不得按姓名和域名猜测邮箱。

页面同时出现姓名与邮箱，不足以证明邮箱归属于该人。来源可信度、任职有效性、邮箱归属和送达状态是不同维度。

合理覆盖来源后仍未找到联系方式时，保留缺失并结束标准调查。业务点名后再扩展，不为填满字段无限搜索。

## 停止与恢复

持久化稳定 ID、研究状态、来源、已完成批次与待处理队列。恢复时只处理未终态企业。A/B/C/D 只影响开发排序，不驱动自动二轮调查。

完成单批后检查结构和增量；国家级交付检查全集关联、重复主体、公式、说明文字和视觉可读性。不能以断点中的 `complete` 替代实际交付验收。
