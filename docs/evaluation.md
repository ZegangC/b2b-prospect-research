## 离线演示的可复验部分

运行 `python demo.py` 应得到 `passed: true`，四条记录分别落在 A/B/C/D，待研究队列为空，两个联系入口需要人工核验。

运行 `python -m unittest discover -s tests -v` 验证以下关键规则：

- 分级阈值和分项上限；拒绝非数值、布尔值和非有限数值。
- 评级变化不自动重启终态企业调查。
- 重复 ID / 显式主体键被拒绝。
- 联系人来源必须关联到证据，证据必须有来源与日期。
- 公司邮箱不得自动归给个人；个人入口必须明确声明来源归属。
- 公开可见不能直接升级为已确认送达。
- 无联系方式可以是合法终态；空批次不能冒充完成。

这些测试验证规则行为，不验证真实网络信息准确率、模型效果或商业价值。
